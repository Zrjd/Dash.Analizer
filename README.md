# DashAnalizer

Приложение для разбора GPS-лога заезда. Оно читает CSV-файл, рисует трассу на карте, воспроизводит заезд по времени и считает круги.

Проект учебный: здесь нет базы данных, сервера и сторонних библиотек. Только C#, WPF и один CSV-файл.

## Что умеет

- Показывает трек на карте OpenStreetMap или на спутниковых снимках Esri.
- Работает без интернета: вместо карты рисует координатную сетку.
- Сохраняет кэш карт в ZIP и переносит его на другой компьютер.
- Проигрывает заезд по времени, как видео.
- Показывает вектор ускорения в текущей или выбранной точке.
- Считает круги по отрезку «начало круга».
- Режет трек на сектора по нескольким линиям поперёк трассы.
- Собирает лучший круг из секторов разных кругов.
- Скрывает и показывает круги на карте по отдельности.
- Ограничивает расчёт коридором трассы: точки вне коридора не влияют на круги и сектора.
- Показывает любой столбец CSV в панели показателей.
- Считает статистику: среднее время круга, лучший и худший круг, время секторов.

## Требования

- Windows 10 или 11.
- .NET 8 SDK. Проверить: `dotnet --version`.
- Visual Studio 2022 с workload «.NET desktop development» — по желанию.
- Интернет — только для подложки карты. Без него приложение работает.

## Запуск

В Visual Studio: откройте `DashAnalizer.sln` и нажмите `F5`.

В PowerShell из папки проекта:

```powershell
dotnet build DashAnalizer.sln
dotnet run --project src\DashAnalizer\DashAnalizer.csproj
```

При запуске приложение само ищет `DATA\LogFile.csv`. Если файл не найден, нажмите «Открыть CSV…».

### Режим без окна

Для проверки лога без графического интерфейса:

```powershell
dotnet run --project src\DashAnalizer -- --stats report.txt DATA\LogFile.csv
```

Отчёт появится в `report.txt`: число точек, пропущенные строки, границы координат и времени.

Можно передать отрезок начала круга четвёртым аргументом:

```powershell
dotnet run --project src\DashAnalizer -- --stats report.txt DATA\LogFile.csv "56.1199,43.6057,56.1201,43.6062"
```

Формат: `широта1,долгота1,широта2,долгота2`. Тогда в отчёт попадут круги и их средние скорости.

Пятый и шестой аргументы задают файлы левой и правой границ трассы. Порядок: `--stats [отчёт] [лог] [линия круга] [левая граница] [правая граница]`.

```powershell
dotnet run --project src\DashAnalizer -- --stats report.txt DATA\LogFile.csv "56.1199,43.6057,56.1201,43.6062" left.txt right.txt
```

В отчёт добавится строка `ZoneInside: <внутри> / <всего>`. Если обе границы не заданы или некорректны, пишется `ZoneSpec: invalid` и фильтр не применяется. Круги и скорости в этом режиме считаются только по точкам внутри коридора.

## Формат CSV

Файл должен быть в кодировке UTF-8. Разделитель — запятая. Значения в кавычках поддерживаются.

Обязательные столбцы:

- `Timestamp` — время в секундах.
- `Latitude` — широта.
- `Longitude` — долгота.

Названия ищутся по началу строки без учёта регистра. Поэтому подходят заголовки `Timestamp (s)`, `Latitude (deg)`, `Longitude (deg)`.

Пример заголовка из `DATA/LogFile.csv`:

```text
Lap #,Timestamp (s),Distance (m),Distance (km),Locked satellites,Latitude (deg),Longitude (deg),Speed (m/s),Speed (kph),Speed (mph),Altitude (m),Bearing (deg),Longitudinal Acceleration (G),Lateral Acceleration (G),X-position (m),Y-position (m),RPM (rpm),Throttle Position (%),Trap name
```

Остальные столбцы необязательны. Любой из них можно включить в панель показателей. Для вектора ускорения нужны `Longitudinal Acceleration (G)` и `Lateral Acceleration (G)`; курс берётся из `Bearing (deg)`.

Строки с пустыми или некорректными `Timestamp`, `Latitude`, `Longitude` пропускаются. Их число видно в строке состояния.

Важно: приложение только читает CSV. Исходный файл не изменяется.

## Как пользоваться

1. Запустите приложение. Загрузится `DATA\LogFile.csv`.
2. Нажмите «▶ Пуск» или клавишу `Пробел`, чтобы начать воспроизведение.
3. Тяните ползунок, чтобы перейти к нужному моменту.
4. Колесо мыши — зум. Зажатая левая кнопка — перемещение карты.
5. «Вписать трек» возвращает весь трек в экран.

### Круги

1. Меню «Круг» → «Задать начало круга…».
2. Кликните первую точку отрезка поперёк трассы.
3. Кликните вторую точку. Отрезок должен пересекать трек.
4. Появится меню «Круги» со списком завершённых кругов.
5. В подменю круга можно показать его на карте или задать цвет.
6. Галочка «Показывать на карте» скрывает и показывает круг. Можно оставить видимыми несколько кругов одновременно.
7. «Показать все круги» возвращает полный трек. Если скрыть все круги, фильтр сбрасывается и снова виден весь трек.
8. Снимите галочку «Учитывать в статистике» в подменю круга, чтобы исключить его из среднего времени, лучшего и худшего круга. Исключённый круг помечается в списке.
9. Исключения и скрытие действуют до смены линии круга или загрузки другого лога. На карте исключённый круг остаётся видимым, если не скрыт отдельно.

Скрытый круг не рисуется совсем. Его участки секторов тоже исчезают. Видимость на карте не влияет на статистику.

`Esc` отменяет режим рисования отрезка. Кнопка «Убрать метку круга» удаляет отрезок и сбрасывает расчёт.

Отрезок сохраняется между запусками. Он не привязан к конкретному файлу лога: если открыть другой заезд в том же районе, отрезок останется.

Первый круг считается от первой точки лога, а не от первого пересечения. Поэтому разминка до линии входит в первый круг.

### Сектора

1. Меню «Сектора» → «Добавить границу…».
2. Кликните две точки линии поперёк трассы. Линия должна пересекать трек.
3. Повторите, чтобы добавить ещё границы. Режим остаётся включённым, пока вы не нажмёте `Esc` или не снимете галочку.
4. Сектора появятся на карте цветными участками. В меню «Сектора» → «Список секторов» они сгруппированы по кругам.
5. В подменю сектора видны время, дистанция и средняя скорость. Пункт «Показать на карте» оставляет на экране только этот сектор.

Нумерация начинается с `С1` на каждом круге: `Круг 2 · С1`, `Круг 2 · С2` и так далее. Если линия круга не задана, нумерация сквозная.

Границы сортируются по времени, поэтому порядок линий в меню не важен. Пересечение линии круга тоже делит сектор. Если две границы совпали, пустой сектор не создаётся.

«Убрать последнюю границу» удаляет одну линию, «Очистить границы» — все. Границы сохраняются между запусками.

### Лучший круг

Лучший круг собирается из секторов разных кругов.

1. Меню «Сектора» → «Лучший круг».
2. Пункт «Собрать автоматически» берёт самый быстрый сектор каждого номера.
3. В подменю «Выбор секторов» → `С1`, `С2`, … видно время, дистанцию и скорость всех вариантов. Клик по варианту заменяет сектор вручную.
4. Итог и состав показаны в блоке «Лучший круг» справа.
5. Галочка «Показать на карте» оставляет на карте только выбранные сектора.

Время лучшего круга — сумма времени выбранных секторов. Дистанция — сумма дистанций. Средняя скорость считается по геометрии: дистанция / время.

Ручной выбор помечен «вручную». «Собрать автоматически» сбрасывает все ручные правки.

Если сектора с каким-то номером нет ни в одном круге, он в состав не попадает. Итог считается по тому, что есть. Строка «Секторов: 12 из 14» показывает, сколько номеров вошло в состав.

Лучший круг не зависит от исключённых из статистики кругов. При смене линии круга или границ секторов ручные правки сбрасываются: нумерация секторов меняется.

### Коридор трассы

Коридор — это полоса вдоль трассы между левой и правой границей. Точки лога вне полосы не участвуют в расчёте кругов и секторов: они остаются на карте серыми.

1. Меню «Трасса» → «Задать левую границу…».
2. Кликайте точки вдоль левого края трассы. Каждый клик добавляет вершину.
3. Двойной клик, `Enter` или правый клик завершает границу. Нужно не меньше двух точек.
4. То же самое для «Задать правую границу…».
5. Когда обе границы готовы, фильтр включается сам. Галочка «Учитывать только точки внутри» отключает и снова включает его.

Направление правой границы не важно: приложение само разворачивает её, сравнивая расстояния между концами. Левая и правая границы могут пересекаться — тогда работает правило чётности, как у обычного многоугольника. Точка ровно на границе считается внутри.

### Правка границ

Готовую границу можно менять без повторного рисования.

- Наведите курсор на вершину. Рядом появится кольцо, курсор сменится на «перемещение». Потяните вершину левой кнопкой мыши.
- Отпустите кнопку — коридор, круги и сектора пересчитаются, файлы границ сохранятся.
- Двойной клик по отрезку между двумя вершинами вставляет новую вершину в это место.
- Клик по вершине выделяет её, вокруг появляется второе кольцо. `Delete` удаляет выделенную вершину, если в границе остаётся не меньше двух точек.
- Клик по пустому месту карты снимает выделение.

Правка работает и во время режима «Задать границу…»: клик по существующей вершине начинает перетаскивание, а не добавляет новую точку. Пока тянете вершину, двигается только линия и заливка; пересчёт запускается при отпускании.

Перетаскивание не требует предварительного выделения. Выделение сбрасывается после переноса, вставки и удаления: при сохранении правая граница может развернуться, и номер вершины стал бы неверным.

Что делает фильтр:

- Пересечения линии круга и линий секторов считаются только на сегментах внутри коридора.
- Дистанция и скорость сектора берутся по участкам внутри коридора.
- Средняя скорость круга считается по точкам внутри коридора.
- Время остаётся реальным: метки `Timestamp` не меняются.
- Сами круги и сектора не выбрасываются. Сектор без пути внутри коридора остаётся с нулевой дистанцией и скоростью, чтобы нумерация не сдвигалась.

Серая часть трека остаётся на карте для ориентира. Цветные участки показывают только то, что вошло в расчёт.

Границы сохраняются между запусками. Галочка фильтра — нет: при следующем запуске фильтр включён, если обе границы загрузились. Смена границ пересчитывает круги и сектора, поэтому исключённые и скрытые круги, а также ручной выбор лучшего круга сбрасываются.

«Убрать границы» удаляет обе границы и файлы настроек. Пока задана только одна граница, фильтр недоступен.

`Esc` выходит из режима рисования границы.

### Вектор ускорения

1. Включите «Вектор ускорения» на панели инструментов или в меню «Вид».
2. Кликните рядом с точкой трека. Время перейдёт на эту точку, появится стрелка.
3. Стрелка показывает направление ускорения. Подпись `0.42 G · 118°` означает модуль и компасный угол: `0°` — север, далее по часовой стрелке.
4. При воспроизведении стрелка движется вместе с текущей точкой.

Нужны колонки `Longitudinal Acceleration (G)` и `Lateral Acceleration (G)`. Курс берётся из `Bearing (deg)`; если её нет, направление считается по самому треку.

Положительное боковое ускорение направлено влево от движения. Если колонок ускорения нет, опция недоступна, а в статусе показывается `—`.

### Показатели

Справа список всех столбцов CSV, кроме времени и координат.

- Галочка включает показатель.
- Текущее значение обновляется при движении ползунка.
- Под числовым показателем видны `min`, `max`, `avg`.
- Кнопки «Все» и «Снять» включают или выключают всё сразу.

По умолчанию включены `Speed (kph)`, `RPM (rpm)`, `Throttle Position (%)`, `Altitude (m)`. Выбор сохраняется.

### Подложка карты

Кнопка «Подложка» включает и выключает карту целиком.

Кнопка «Спутник» переключает слой: выключена — OpenStreetMap, включена — спутниковые снимки Esri World Imagery. При включении спутника подложка включается автоматически. Повторное выключение возвращает OpenStreetMap.

Выбор спутника действует только в текущем сеансе и не сохраняется.

Подпись внизу карты показывает источник активного слоя: `© Участники OpenStreetMap` или `© Esri, Maxar, Earthstar Geographics`.

Без интернета тайлы не загружаются, и остаётся координатная сетка. Это нормально: трек, круги и показатели работают.

### Перенос кэша карт

Загруженные тайлы хранятся на диске. Их можно перенести на другой компьютер, чтобы карта работала без интернета.

1. Меню «Файл» → «Кэш карт» → «Экспорт в ZIP…».
2. Укажите файл архива. Имя по умолчанию: `DashAnalizer-map-cache-ГГГГММДД.zip`.
3. На другом компьютере: «Файл» → «Кэш карт» → «Импорт из ZIP…».
4. Выберите архив. Тайлы добавятся к существующему кэшу.

Импорт не удаляет старые тайлы. Совпадающие файлы перезаписываются. После импорта карта сразу читает тайлы с диска, перезапуск не нужен.

Архив содержит только тайлы OSM и спутника. Настройки (`lapline.txt`, `sector-lines.txt`, `indicators.txt`) в него не входят.

Пустой кэш не экспортируется: приложение покажет сообщение и не создаст пустой архив.

## Как это работает

Короткая цепочка:

```text
CSV -> TrackLogReader -> TrackLog -> MainWindow -> TrackMapControl -> экран
```

1. `TrackLogReader` читает файл один раз.
2. Находит столбцы времени и координат.
3. Создаёт список точек `TrackPoint`.
4. Для каждого столбца создаёт `LogColumn` со значениями и статистикой.
5. `MainWindow` передаёт точки карте и заполняет панель показателей.
6. `TrackMapControl` переводит координаты в пиксели и рисует трек.

### Карта

Карта использует проекцию Web Mercator.

1. Долгота и широта переводятся в координаты мира от 0 до 1.
2. Зум задаёт размер мира: `256 * 2^zoom` пикселей.
3. Точка на экране = `(координата мира - центр) * размер мира + половина окна`.

Колесо мыши меняет зум и оставляет точку под курсором на месте. Перетаскивание меняет центр карты.

Тайлы карты берутся из кэша в памяти, потом с диска, потом из сети. Если тайла нет, рисуется сетка.

`TrackMapControl` держит два независимых кэша: OpenStreetMap и спутниковый. У них разные источники, разные папки и разные расширения файлов. Активный слой выбирает свойство `ShowSatellite`.

### Круги

Пользователь задаёт отрезок поперёк трассы. `LapCounter` проверяет каждую пару соседних точек трека и ищет пересечение с этим отрезком.

Чтобы дрожание GPS не создавало ложные круги, два пересечения ближе 10 точек считаются одним.

Время круга — разница `Timestamp` между пересечениями. Средняя скорость берётся из столбца `Speed (kph)`. Если столбца нет, скорость считается по расстоянию и времени.

### Вектор ускорения

`AccelerationCalculator` берёт продольное и боковое ускорение из CSV. Продольное направлено вперёд, боковое — влево. Курс задаёт, куда смотрит «вперёд».

Из двух составляющих получается вектор в осях восток/север. Его длина — модуль ускорения в `G`, угол — компасное направление. Карта переводит вектор в экранные пиксели и рисует стрелку.

Если курс в логе пуст, он считается по соседним точкам трека. Если пуста одна составляющая ускорения, рисуется только вторая.

### Сектора

`SectorCounter` ищет пересечения каждой линии границы с треком. Все пересечения сортируются по индексу точки, повторы убираются.

Дальше трек режется на интервалы между соседними границами. Время сектора — разница `Timestamp`, дистанция — сумма расстояний по формуле гаверсинуса, скорость — дистанция / время.

Пересечение линии круга входит в список границ. На нём номер сектора сбрасывается на 1. Поэтому `C1` каждого круга — это первый участок после линии круга.

### Лучший круг

`BestLapBuilder` группирует все сектора по номеру. В каждой группе берётся сектор с минимальным временем. Ручное переопределение задаёт номер круга для нужного номера, если такой сектор существует.

`BestLap` хранит состав, сумму времени, сумму дистанции и ожидаемое число номеров. Карта получает состав через свойство `BestLapSectors` и рисует только эти участки.

### Коридор трассы

`TrackArea` хранит левую и правую ломаные. Замкнутый контур — левая ломаная, затем правая в обратном порядке. Концы замыкаются сами, отдельная линия старта не нужна.

`TrackZone.Create` проверяет, что в каждой границе не меньше двух вершин, и разворачивает правую границу, если её концы ближе к противоположным концам левой.

`TrackZone.Contains` проверяет попадание точки методом трассировки луча. Сначала точка проверяется на принадлежность любому отрезку контура: точка на границе считается внутри. Пересекающиеся границы дают правило чётности.

`TrackZone.BuildMask` строит массив `bool` по всем точкам лога. Маска передаётся в `LapCounter.FindCrossings`, `LapCounter.AverageSpeedKph`, `SectorCounter.CollectBoundaries` и `SectorCounter.BuildSectors`. Сегмент, у которого хотя бы одна точка вне коридора, не учитывается.

`TrackMapControl` получает границы через свойства `LeftBoundary` и `RightBoundary`, а маску — через `ZoneMask`. Внутри коридора трек рисуется обычными цветами, снаружи — серым. Режимы лучшего круга, одного сектора и фильтра кругов рисуют только участки внутри коридора.

## Где хранятся настройки

```text
%LOCALAPPDATA%\DashAnalizer\lapline.txt        отрезок начала круга
%LOCALAPPDATA%\DashAnalizer\sector-lines.txt   линии границ секторов
%LOCALAPPDATA%\DashAnalizer\track-left.txt     левая граница коридора трассы
%LOCALAPPDATA%\DashAnalizer\track-right.txt    правая граница коридора трассы
%LOCALAPPDATA%\DashAnalizer\indicators.txt     выбранные показатели
%LOCALAPPDATA%\DashAnalizer\Tiles\             кэш тайлов OSM: {z}\{x}\{y}.png
%LOCALAPPDATA%\DashAnalizer\Tiles\satellite\   кэш спутниковых тайлов: {z}\{x}\{y}.jpg
```

`%LOCALAPPDATA%` обычно равен `C:\Users\<имя>\AppData\Local`.

Файлы можно удалить. Приложение создаст их заново. Ошибки записи не мешают работе.

Лучший круг, видимость кругов и галочка фильтра коридора живут только в текущем сеансе и не сохраняются. Сами границы коридора сохраняются.

## Если что-то не работает

**Карта пустая, видна только сетка.**
Нет интернета или сервер тайлов недоступен. Трек и круги всё равно работают.

**Спутниковая карта пустая, а обычная работает.**
Сервер Esri недоступен или блокирует запросы. Выключите «Спутник» — вернётся OpenStreetMap. Можно перенести готовый кэш через «Файл» → «Кэш карт» → «Импорт из ZIP…».

**Импорт кэша не помог.**
Проверьте, что архив содержит папки `{z}\{x}\{y}.png` или `satellite\{z}\{x}\{y}.jpg`. Посторонние файлы и небезопасные пути пропускаются.

**«Отрезок не пересекает трек — задайте заново».**
Линия не пересекает трассу. Нарисуйте её поперёк трека, а не вдоль.

**«Файл LogFile.csv не найден».**
Нажмите «Открыть CSV…» и выберите файл вручную. Либо положите `LogFile.csv` в папку `DATA` рядом с проектом.

**«В заголовке не найдены обязательные колонки».**
Проверьте, что в первой строке есть `Timestamp`, `Latitude`, `Longitude`.

**«В файле нет ни одной корректной строки».**
Проверьте разделитель — нужна запятая. Проверьте, что координаты и время записаны числами.

**Часть строк пропущена.**
В этих строках пустое или некорректное время либо координаты. Число пропусков показано в строке состояния.

**Стрелка ускорения не появляется.**
В логе нет колонок `Longitudinal Acceleration (G)` и `Lateral Acceleration (G)` либо в выбранной точке обе пусты. В статусе будет `Ускорение: —`.

**Стрелка ускорения смотрит не туда.**
Направление зависит от знака бокового ускорения в логе. Приложение считает положительное боковое ускорение направленным влево. У некоторых логгеров знак противоположный.

**Сектора не появились.**
Проверьте, что линия границы пересекает трек, а не проходит рядом. В меню «Сектора» → «Список секторов» будет надпись «Линии не пересекают трек».

**Нумерация секторов начинается не с 1.**
Номер сбрасывается на линии круга. Если линия круга не задана, нумерация сквозная. Задайте линию круга в меню «Круг».

**Лучший круг включает странный сектор.**
Проверьте ручные правки в «Сектора» → «Лучший круг» → «Выбор секторов». Нажмите «Собрать автоматически», чтобы вернуть самый быстрый вариант каждого номера.

**Номера в лучшем круге идут с пропусками.**
Некоторых номеров секторов нет ни в одном круге. Они пропускаются, итог считается по существующим.

**Круги и сектора исчезли после включения фильтра.**
Линия круга или границы секторов проходит вне коридора, поэтому пересечений нет. Расширьте коридор, подвиньте границы или снимите галочку «Учитывать только точки внутри».

**Фильтр коридора недоступен.**
Задана только одна граница или ни одной. Нарисуйте обе: «Трасса» → «Задать левую границу…» и «Задать правую границу…».

**Серая часть трека осталась на карте.**
Так и должно быть: серый цвет показывает точки вне коридора. В расчёт они не входят.

**Скорость сектора стала 0.**
Внутри коридора не осталось ни одного сегмента этого сектора. Время сектора сохраняется, дистанция и скорость нулевые.

**Граница нарисовалась не в ту сторону.**
Правая граница разворачивается автоматически, рисовать её в одном направлении с левой не нужно.

**Не получается сдвинуть вершину границы.**
Наведите курсор точно на точку: должно появиться кольцо, а курсор сменится на «перемещение». Затем тяните левой кнопкой. Если включён режим «Задать границу…», клик по вершине всё равно начинает перетаскивание, а не добавляет новую точку.

**Двойной клик не вставляет точку.**
Клик должен попасть на отрезок между двумя вершинами готовой границы, а не на саму вершину. Концы отрезка исключены: рядом с вершиной вставка не срабатывает.

**Delete не удаляет вершину.**
Сначала кликните по вершине, чтобы появилось кольцо выделения. Удаление блокируется, если в границе осталось бы меньше двух вершин.

**Приложение зависло при открытии большого файла.**
Файл читается в главном потоке. Дождитесь окончания загрузки.

## Словарь

- **CSV** — текстовый файл с таблицей, где столбцы разделены запятыми.
- **GPS** — спутниковая навигация, источник координат.
- **Точка трека** — одно измерение: время, широта, долгота.
- **Круг** — участок трассы от одного пересечения стартовой линии до следующего.
- **Сектор** — участок между двумя соседними границами внутри круга.
- **Лучший круг** — набор самых быстрых секторов, по одному на номер.
- **Коридор трассы** — полоса между левой и правой границей; задаёт, какие точки участвуют в расчёте.
- **Тайл** — квадратная картинка карты размером 256×256 пикселей.
- **WPF** — библиотека Windows для окон и рисования.
- **DependencyProperty** — свойство WPF, изменение которого запускает перерисовку.
- **G** — единица ускорения, примерно 9,81 м/с².
- **InvariantCulture** — правила чисел с точкой как разделителем, независимо от языка Windows.

## С чего начать читать код

1. `Models/TrackPoint.cs` — самая простая структура.
2. `Services/TrackLogReader.cs` — как CSV превращается в точки.
3. `Services/LapCounter.cs` — геометрия и круги, без WPF.
4. `Services/SectorCounter.cs` — нарезка на сектора, без WPF.
5. `Controls/TrackMapControl.cs` — координаты и рисование. Начните с методов `UnitX`, `UnitY`, `UnitToScreen`.
6. `MainWindow.xaml.cs` — как окно связывает всё вместе.
7. `Services/TileStore.cs` — кэш и сеть.

Полезно менять по одному небольшому месту и сразу запускать приложение. Например, цвет трека в `TrackMapControl` или набор показателей по умолчанию в `MainWindow`.
